# zju-connect 本地修复

发布构建固定使用 zju-connect v1.3.1（提交 `5d7f5b11fcf231f72a0ec0d888bf0f2eadcce1da`），并应用同目录的补丁。补丁修复 EasyConnect 重连失败时保存空 TLS 连接、并发关闭时重复退出的问题；服务器仍可能主动终止会话。

补丁也在 VPN 栈入口统计收发字节，并输出 `EZ4PRO_TRAFFIC` 累计值供界面计算实时速率。统计覆盖 L3 和 TCP 隧道，不包含系统其他网络流量。界面会过滤这些内部数据行，避免刷屏。

上游发布新核心时，需要检查相关修复、更新固定提交、重新应用或移除补丁，并在本地验证核心和各平台构建。发布流程会在补丁无法应用时停止，而不会悄悄使用未修复的核心。
